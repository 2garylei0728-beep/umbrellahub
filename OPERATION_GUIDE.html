櫃子通電後，兩條控制路徑同時在線，互為備援：

路徑訪問方式適用場景
互聯網手機掃櫃身 QR Code → 開網站日常使用、任何有網的地方
本地手機連櫃子熱點 Umbrella → 開 192.168.4.1展場斷網、校園網故障、現場調試

兩者操作同一塊櫃子、同一份格位數據；任一路徑下達的指令都即時生效。展場完全斷網也能正常存傂取傂。

2.2 用戶端操作

  1. 存傂：按「我要存傂」→ 櫃子轉盤開門 → 網站顯示 4 位取傂碼（只顯示一次，請截圖或抄下）→ 放傂 → 門自動關閉
  2. 取傂：輸入 4 位碼 → 櫃子轉到對應格、開門 → 取傂 → 門自動關閉
  3. 管理操作（密碼 8888，頁面底部「管理／除錯」展開）：開門／關門／清空全部／對位 1-8 格／轉到指定格／查看各格取傂碼
  4. 即時指令監控：頁面卡片即時顯示 ESP32 收到的每條命令與回執，當場驗證櫃子是否正常工作

三、無互聯網環境（備用模式）

3.1 運作原理

櫃子通電即開熱點 Umbrella（密碼 12345678）——不管有沒有校園網，熱點永遠在。手機連熱點 → 瀏覽器開 192.168.4.1 → 本地控制頁（存傂／取傂／管理／WiFi 設定，功能完整）。指令不經過雲端，直達 ESP32。

3.2 兩種環境對比

互聯網本地
訪問方式掃 QR Code／開網址連熱點 + 輸 IP
同時控制人數不限熱點上限約 4 台
取傂碼顯示網站彈出（只一次）本地頁彈出（只一次）
管理密碼88888888
斷網影響退避後自動恢復完全不受影響

五、故障排查速查表

症狀最可能原因解法
網站顯示「櫃子離線」櫃子 WiFi 或中繼短暫斷線等 2 分鐘（自愈機制自動重啟 WiFi／板子）；串口 netinfo 查看
網站卡在「連接中…」手機網絡阻擋 WebSocket換 WiFi／用無痕模式打開
櫃子很久連不上場地 WiFi場地加密不相容或被封鎖串口 newmac 換 MAC；或配網頁重新設定帳密
本地頁 192.168.4.1 打不開手機沒連熱點／信號弱確認連的是 Umbrella；靠近櫃子再試
按存傂沒反應櫃子運作中或已滿看指示燈；頁面查看空位數
取傂碼錯誤輸錯／碼已用過取傂碼只用一次；核對後重輸
展場當天完全斷網—走本地路徑：連 Umbrella → 192.168.4.1（功能完整）
